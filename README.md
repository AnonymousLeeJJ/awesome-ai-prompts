## 🤔 为什么做这个库？

网上提示词千千万，但大多数是「正确的废话」——一句「你是 xx 专家，请帮我 xx」就收工了。

这个库只收录**结构化、可直接复制、经过真实场景验证**的提示词。每条提示词都遵循三个标准：

- ✅ **有结构**：角色 + 规则 + 步骤 + 输出格式，让模型稳定输出
- ✅ **有细节**：包含评分标准、边界条件、禁止事项，不是一句话糊弄
- ✅ **有占位**：`【填写】` 处替换为你的内容即可用，零学习成本

## 🚀 快速开始

1. 打开 **[在线浏览页面](https://YOUR_USERNAME.github.io/awesome-ai-prompts/)**（推荐，支持搜索和一键复制）

3. 把 `【填写】` 占位符替换成你的内容，粘贴到任意 AI 对话工具（ChatGPT / Claude / 元宝 / 豆包 / DeepSeek 等）
